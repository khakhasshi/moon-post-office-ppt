# 《消失的第七页航海日志》HTML课件使用说明

1. 先把整个课件文件夹从压缩包中解压出来，再双击 `index.html`，使用 Chrome、Edge 或 Safari 打开。不要在压缩包预览窗口中直接运行。
2. `← / →`：前后翻页；`F`：全屏；`M`：开关环境声音；`T`：打开或关闭讲师提示；`R`：重置当前页。
   点击“全屏”或按 `F` 只负责切换全屏，不会自动播放任何声音。
3. 顶部“Ⅱ”控制声音暂停/继续；“低”用于孩子表达时降低环境声音。
4. 第1页为封面；第2—5页通过异常信号、信息恢复、档案解锁和任务确认进入故事；第6—12页用连续大图完整讲述故事；第13—20页逐段训练台词。
5. 开场与故事大图中的金色按钮由老师根据孩子的观察和回答手动点击；按 `R` 可恢复当前页的初始状态。
6. 每个台词训练页直接显示：当前台词、停连标记、关键词重音、三步练法和听众接收结果。
7. 台词中的 `/` 表示短停，`//` 表示明显停顿；黄色词语是本段需要加重并送达听众的重音。
8. 每段按“孩子第一遍—老师只调整一个问题—同一孩子第二遍”完成，下一段优先邀请不同孩子。
9. 按 `T` 打开的讲师提示中，可查看教师触发、训练重点、进入下一步要求，并记录六名孩子的参与情况。
10. 第21页为单页完整稿件，所有台词同时显示；表演过程中保持本页不动，不再切换图片或页面。稿件标题右侧是浏览器原生作品配乐播放器，在全屏状态下直接点击播放或暂停，也可以拖动进度条。
11. 第22页为无配乐的观点表达，课件依次呈现核心判断、故事依据和升华追问。
12. `assets` 文件夹必须与 `index.html` 放在同一文件夹内，不要单独移动图片、声音或字体文件。
13. 完整作品配乐为 `Voxscape`（Eugenio Mininni）；已去除开头过长的弱声段，课件内版本约4分35秒，保存在 `assets/voxscape.mp3`，无需联网。来源与授权信息见 `音乐授权说明.md`。
14. 正式上课前，请在实际教室电脑和投影设备上完整试播一次，并按现场音响调低环境声音；默认配乐音量为 16%，点击“低”后约为 6%。
15. 开场异常信号已保存为本地文件 `assets/distress-signal.mp3`；中文展示字体已精简嵌入为 `assets/course-serif.woff2`，换电脑无需另装字体。字体来源和授权见 `字体说明.md` 与 `字体授权_OFL-1.1.txt`。
